Nu er det på tide at få nogle **asteroider**! Efter dette niveau ligger der 10 asteroider rundt omkring i rummet – og hver gang du starter spillet, ligger de nye steder.

**Det nye i dag:** `random` – tilfældighed. Du har brugt `random` før på intro-holdet. Nu bruger vi `random.randint(a, b)`, som giver et tilfældigt **helt tal** mellem `a` og `b`. Begge ender er med, så `random.randint(0, 3)` kan give `0`, `1`, `2` eller `3`.

## Tilfældige steder

Vores skærm er 1200 pixels bred og 800 pixels høj, og midten er (0, 0). Så x går fra `-HALF_WIDTH` (-600) til `HALF_WIDTH` (600), og y går fra `-HALF_HEIGHT` (-400) til `HALF_HEIGHT` (400).

<img src={import.meta.env.BASE_URL + "images/coordinate-system.svg"} alt="Koordinatsystem med x-aksen vandret og y-aksen lodret, og (0, 0) i midten" />

Prøv at finde 5 tilfældige steder til asteroider:

```python.run
import random

HALF_WIDTH = 600
HALF_HEIGHT = 400

for i in range(5):
    x = random.randint(-HALF_WIDTH, HALF_WIDTH)
    y = random.randint(-HALF_HEIGHT, HALF_HEIGHT)
    print(f"Asteroide {i}: x = {x}, y = {y}")
```

Kør koden et par gange. Får du de samme tal hver gang? Prøv at ændre `5` til `10`.

Her bliver det tegnet med turtle. Skærmen her i browseren er lidt mindre, så vi bruger 180 i stedet for 600 og 400:

```python.run
import random
import turtle

t = turtle.Turtle()
t.color("gray")
for i in range(8):
    x = random.randint(-180, 180)
    y = random.randint(-180, 180)
    t.penup()
    t.goto(x, y - 20)
    t.pendown()
    t.circle(20)
```

Prøv at ændre `t.circle(20)` til `t.circle(random.randint(5, 40))`. Så får asteroiderne også tilfældige størrelser!

## En klasse til asteroiden

Hvad skal en asteroide være for en slags ting? Den skal kunne vises på skærmen og stå et sted – så den er selvfølgelig en `Turtle`! Lige nu skal den ikke kunne andet end at blive lavet:

```python
class Asteroid(turtle.Turtle):

    def __init__(self):
        super().__init__()
```

## Tilfældighed

For at bruge `random` skal vi først **importere** det – ligesom vi gør med `turtle`:

```python
import random
```

- [ ] Indsæt koden øverst i filen, lige under `import turtle`

## Hver ny asteroide (`__init__`)

Når en ny asteroide bliver lavet, skal den:

- Have form som en cirkel: `self.shape("circle")`
- Være 3 gange så stor som normalt: `self.shapesize(3, 3)`
- Have hvid kant og samme fyldfarve som baggrunden, så den ser hul ud: `self.color("white", BG_COLOR)`
- Løfte pennen, så den ikke tegner streger: `self.penup()`

```python
        self.shape("circle")
        self.shapesize(3, 3)
        self.color("white", BG_COLOR)
        self.penup()
```

- [ ] Indsæt koden i `__init__`-funktionen i `Asteroid`, under `super().__init__()`. Den skal rykkes ind lige så meget som `super()`.

## En tilfældig position

Nu skal asteroiden have et tilfældigt sted på skærmen. Hvad er vores `a` og `b`? For x er det `-HALF_WIDTH` og `HALF_WIDTH`, og for y er det `-HALF_HEIGHT` og `HALF_HEIGHT`. Til sidst flytter vi asteroiden derhen med `goto`:

```python
        x = random.randint(-HALF_WIDTH, HALF_WIDTH)
        y = random.randint(-HALF_HEIGHT, HALF_HEIGHT)
        self.goto(x, y)
```

- [ ] Indsæt koden i `__init__`-funktionen i `Asteroid`, under `self.penup()`

:::note[Hvorfor penup først?]
Hvis pennen var nede, ville asteroiden tegne en streg fra midten af skærmen hen til sin plads. Derfor skal `self.penup()` stå **før** `self.goto(x, y)`.
:::

## Lav asteroiderne, når spillet starter

Vi skal have en **liste** med alle asteroiderne – præcis som vi har en liste med kugler. Først en tom liste, og så en `for`-løkke, der laver `MAX_ASTEROIDS` asteroider og lægger dem i listen med `append`:

```python
# Create asteroids
asteroids = []
for i in range(MAX_ASTEROIDS):
    asteroids.append(Asteroid())
```

Hver gang `Asteroid()` bliver kaldt, kører `__init__`, og der bliver lavet en ny asteroide et nyt tilfældigt sted.

:::tip[Typiske fejl]
- `NameError: name 'random' is not defined`: Du mangler `import random` øverst.
- `NameError: name 'Asteroid' is not defined`: Klassen skal stå i `# CLASSES`, som er **før** `# GAME SETUP`. Python læser oppefra og ned.
- Der kommer kun én asteroide: Er `asteroids.append(Asteroid())` rykket ind under `for`-løkken?
- Streger hen over skærmen: `self.penup()` skal stå før `self.goto(x, y)`.
:::

```python.run norun="true"
import turtle
import random

"""
Let's add some Asteroids
"""

#
#  CONSTANTS
#

SCREEN_WIDTH = 1200
SCREEN_HEIGHT = 800
BG_COLOR = "black"

GAME_TICK = 20  # milliseconds, lower means faster game
ROTATE_SPEED = 5  # turn 5 degrees each tick
PLAYER_SPEED = 10  # Pixels to move player each tick
BULLET_SPEED = PLAYER_SPEED * 2  # Double of player speed
BULLET_LIFETIME = 75  # game ticks
MAX_BULLETS = 10
RELOAD_TIME = 5  # ticks between reload
MAX_ASTEROIDS = 10

HALF_WIDTH = int(SCREEN_WIDTH / 2)
HALF_HEIGHT = int(SCREEN_HEIGHT / 2)

#
#  Classes
#


class Bullet(turtle.Turtle):

    def __init__(self):
        super().__init__()
        self.shape("square")
        self.color("light grey")
        self.shapesize(stretch_wid=0.2, stretch_len=0.2)
        self.penup()
        self.hideturtle()
        self.active = False
        self.ttl = BULLET_LIFETIME

    def fire(self, start):
        self.active = True
        self.ttl = BULLET_LIFETIME
        self.setposition(start.xcor(), start.ycor())  # Move the bullet to the player
        self.setheading(start.heading())  # set the same heading as the player
        self.showturtle()  # show the bullet

    def move(self):
        self.forward(BULLET_SPEED)
        move_if_out_of_bounds(self)

        self.ttl -= 1
        if self.ttl < 0:
            self.hideturtle()
            self.active = False


class Player(turtle.Turtle):

    def __init__(self):
        super().__init__()
        self.shape("triangle")
        self.color("light grey", BG_COLOR)
        self.shapesize(stretch_wid=0.75, stretch_len=1.5)  # Stretch the triangle to be pointy
        self.penup()  # to not draw lines

        self.fire_cooldown = 0

    def shoot(self, inactive_bullet):
        if self.fire_cooldown == 0:
            inactive_bullet.fire(self)
            self.fire_cooldown = RELOAD_TIME

    def cooldown(self):
        if self.fire_cooldown > 0:
            self.fire_cooldown -= 1


class Asteroid(turtle.Turtle):

    def __init__(self):
        super().__init__()
        self.shape("circle")
        self.shapesize(3, 3)
        self.color("white", BG_COLOR)
        self.penup()
        x = random.randint(-HALF_WIDTH, HALF_WIDTH)
        y = random.randint(-HALF_HEIGHT, HALF_HEIGHT)
        self.goto(x, y)



#
#  GAME SETUP
#

# Set up the screen
screen = turtle.Screen()
screen.setup(SCREEN_WIDTH, SCREEN_HEIGHT) # width and height
screen.bgcolor(BG_COLOR) # background color
screen.tracer(0) # disable the built in movement animation of turtle


# Make a turtle for the player
player = Player()

# Create bullets
bullets = []
for i in range(MAX_BULLETS):
    bullets.append(Bullet())

# Create asteroids
asteroids = []
for i in range(MAX_ASTEROIDS):
    asteroids.append(Asteroid())


#
#  EVENTS
#

keys_pressed = {
    "Left": False,
    "Right": False,
    "Up": False,
    "space": False
}

# Make the spaceship move
def press_left():
    keys_pressed["Left"] = True

def release_left():
    keys_pressed["Left"] = False

def press_right():
    keys_pressed["Right"] = True

def release_right():
    keys_pressed["Right"] = False

def press_forward():
    keys_pressed["Up"] = True

def release_forward():
    keys_pressed["Up"] = False

def press_fire():
    keys_pressed["space"] = True

def release_fire():
    keys_pressed["space"] = False


screen.listen()
screen.onkeypress(press_left, "Left")
screen.onkeypress(press_right, "Right")
screen.onkeypress(press_forward, "Up")
screen.onkeypress(press_fire, "space")
screen.onkeyrelease(release_left, "Left")
screen.onkeyrelease(release_right, "Right")
screen.onkeyrelease(release_forward, "Up")
screen.onkeyrelease(release_fire, "space")

#
#  BEHAVIOURS
#


def move_if_out_of_bounds(t: turtle.Turtle):
    # Border checking for bullet
    x = t.xcor()
    y = t.ycor()
    # abs turns any number to a positive number
    if x > HALF_WIDTH:  # too far right
        t.goto(-HALF_WIDTH, y)
    elif x < -HALF_WIDTH:  # too far left
        t.goto(HALF_WIDTH, y)
    if y > HALF_HEIGHT:  # too far up
        t.goto(x, -HALF_HEIGHT)
    elif y < -HALF_HEIGHT:  # too far down
        t.goto(x, HALF_HEIGHT)


def move_spaceship():
    if keys_pressed["Left"]:
        player.left(ROTATE_SPEED)
    if keys_pressed["Right"]:
        player.right(ROTATE_SPEED)
    if keys_pressed["Up"]:
        player.forward(PLAYER_SPEED)
        move_if_out_of_bounds(player)

    
def move_bullets():
    player.cooldown()
    inactive_bullet = None
    for bullet in bullets:
        if bullet.active:
            bullet.move()
        else:
            inactive_bullet = bullet

    if keys_pressed["space"] and inactive_bullet:
        player.shoot(inactive_bullet)


#
#  GAME LOOP
#

def update():
    move_spaceship()
    move_bullets()

    screen.update()
    screen.ontimer(update, GAME_TICK) # this calls the game loop again for the next tick


#
#  START THE GAME
#

update() # call the game loop to start the game
screen.mainloop() # don't close the window
```
